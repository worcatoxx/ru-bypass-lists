# ru-bypass-lists
🇷🇺 **Последнее обновление / Last updated:** 10 мая 2026 г. / May 10, 2026

Ультимативный набор списков (домены и IP-адреса) для настройки раздельного туннелирования в клиентах вроде **Passwall, Xray, v2ray, Sing-box** и других. 
Списки оптимизированы для комфортного использования в РФ: локальный трафик идет напрямую, заблокированный — через VPN.

Ultimate collection of domains and IPs for split tunneling (Passwall, Xray, v2ray, Sing-box). 
Optimized for RU region: local traffic is routed directly, blocked traffic goes through the VPN.
